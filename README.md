
# 🔮 Mood Lab｜心理測驗研究所

## 專案介紹
Mood Lab 是一個以心理測驗為主題的互動網站，
希望讓使用者透過輕鬆有趣的小測驗，
探索自己的個性與生活喜好。

## 網站功能
- 🍰 你是哪種甜點人格？
- 🐰 你的內心住著哪種小動物？
- ✨ 你適合生活在哪個魔法世界？
- 每個測驗包含五道選擇題
- 根據答案計算並顯示測驗結果
- 支援重新測驗、返回首頁及複製結果

## 網站設計
採用粉色、紫色與奶油色的馬卡龍配色，
搭配圓角卡片與柔和的視覺風格，
讓使用者有輕鬆、療癒的使用體驗。

## 開發工具
- HTML
- CSS
- JavaScript
- GitHub Pages

## AGENTS.md
本專案透過 AGENTS.md 定義網站風格、
檔案結構、測驗格式與 AI 開發規則。

未來可以依照相同規則，
持續新增不同主題的心理測驗，
並維持一致的網站設計。
